ONE MORE WINE — 2026BRANDING / E-COMMERCE
01 / O PROJETO

Mais vinho.
Menos complicação.

Uma identidade visual para aproximar o vinho do cotidiano e transformar a escolha de uma garrafa em uma experiência simples, convidativa e cheia de personalidade.

O projeto explora uma linguagem direta, cores expressivas e referências sensoriais do universo do vinho. A proposta é equilibrar a cultura da bebida com uma comunicação acessível, sem depender dos códigos tradicionais de sofisticação.

02 / DIREÇÃO CRIATIVA

Uma marca feita
para o próximo gole.

O sistema visual combina tipografia de personalidade, uma paleta inspirada em ingredientes e texturas naturais e aplicações digitais pensadas para comunicar de forma clara.
